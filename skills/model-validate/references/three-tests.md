# 三大检验

## 误差分析

- 真值 / 预测或方案值 / 误差要定义。
- 常用：AE、RE、MAPE、MSE、RMSE、R²。优化题用约束违反与目标改进率。
- 必须对照朴素规则或 baseline。

## 灵敏度分析

- 问：参数动一点，输出动多少。
- 局部：单参数扰动。可报 S ≈ Δy/Δx（注意量纲，最好同时报百分比）。
- 判定经验：±10% 参数导致核心输出变 >15% → 必须讨论，不能写“不敏感”。

## 稳健性检验

- 问：换假设或结构后，结论还在不在。
- 手段：换求解器、抽 80% 样本、极端需求、放宽约束。
- 结论应是「排序是否变」「可行是否仍可行」，不是再报一遍 RMSE。
