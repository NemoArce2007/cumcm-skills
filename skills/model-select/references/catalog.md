# 选型目录（给 model-select 读）

只列国赛高频、可推导、可解释的。没有的模型不是禁区，但必须多写 why 与风险。

## 评价

流程：指标 → 赋权 → 得分/排序。

| 方法 | 何时 | 不要 |
| --- | --- | --- |
| AHP | 缺数据、要结构化经验 | 冒充客观 |
| 熵权 | 有完整数值、要客观权重 | 指标无区分度时盲用 |
| TOPSIS | 方案排序（需先有权重） | 单独当赋权 |
| 模糊综合 | 等级语言、满意度 | 本可精确量化时故弄玄虚 |
| 机器学习分级 | 大样本且可交叉验证 | 样本<指标数仍上黑箱 |

稳妥组合：少数据 AHP+TOPSIS；多数据 熵权+TOPSIS。

## 预测

稳妥：趋势平稳用回归；短序列可 GM(1,1)；有季节用 ARIMA/分解。进阶 ML 必须有时间外验证，禁止打乱时序随机划分。

## 优化

| 类型 | 特征 |
| --- | --- |
| LP | 线性、连续 |
| IP / 0-1 | 整数或开关 |
| NLP | 平方、乘积、超越 |
| 多目标 | 冲突目标，报告权衡不是单点吹“最优” |
| 组合 | TSP、调度；启发式要多次种子 |

精确可解时不要只用 GA。大规模再上启发式，并报告 gap 或与可行规则的改进。

## 机理

| 类型 | 何时 |
| --- | --- |
| 微分方程 | 连续动态、传热、运动、衰减 |
| 因果归因 | 问“谁影响大”，不是物理场 |
| 结构拆解 | 先分模块再量化 |
| 系统动力学 | 宏观反馈、长期存量流量 |

机理题的数据多用于标定参数，不是用来替换定律。
