# 学术声音

AI 味 = 模板结构 + 过平滑 + 无证据 + 无决策痕迹。不是某几个词本身。

## 有效改法（按效力）

1. 换事实：写入本题数字、异常点、失败模型。  
2. 换逻辑顺序：约束 → 为什么用此法 → 本题怎么做。  
3. 换句式。  
4. 换词（最弱）。

## 不要动

公式、符号、标准模型名、单位、图号、算法依赖顺序。

## 定义

标准定义：引用 + 本题怎么用。不要把教材定义改成口语硬洗。

## 结果段

先写表/图上的具体变化，再解释。禁止先写物理结论再不贴数。

模板摘要里的「各模型性能优越、结论可靠」「为……提供理论依据和决策参考」一律删掉，换成本题数字或适用边界。

## Agent 角色

优先当审稿人：标空泛、标不一致。不要整章代写后无法核验。
